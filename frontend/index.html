❓ FAQ

¿Cómo funciona la detección P/S?

STA/LTA sobre la traza vertical pre-filtrada 2-15 Hz. Score>3 activa P. Para S se estima desde Δt P-S con Vp/Vs=1.73.

¿Qué es HVSR?

Método Nakamura (1989): H/V = sqrt(PSD_H1 × PSD_H2) / PSD_Z. El pico f₀ aproxima la frecuencia de resonancia del suelo.

¿Qué calibración de magnitud se usa?

ML Richter con función de atenuación CSN Chile: log₁₀(A₀) = 0.020·R + 2.10 (R<70 km) o 0.0038·R + 3.00 (R≥70 km).

¿Cómo exportar datos?

Usa el botón "Generar Reporte" en la página Reporte. Descarga HTML autocontenido con gráficos o Excel con IMs y picks.
